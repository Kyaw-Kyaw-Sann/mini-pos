# Mini POS

A simple Point of Sale application built with React, TypeScript, and Tailwind CSS.

## Features

- Dashboard summaries
- Product add, edit, delete, search, and category filter
- Product details
- POS cart with quantity controls
- Cash checkout and change calculation
- Automatic stock updates
- Sales history and sale details
- Responsive layout

## Tech Stack

- React
- TypeScript
- Vite
- React Router
- Tailwind CSS
- Lucide React
- React Hot Toast

## Run Locally

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

## Note

This project uses sample data stored in React state. Data resets when the browser is refreshed. It does not include a backend, authentication, database, or real payment integration.
